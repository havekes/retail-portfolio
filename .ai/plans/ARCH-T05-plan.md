## Plan

**Approach:** Reorder the three `MarketGateway` price methods to symbol-first signatures with `security_id: SecurityId | None = None` as the final keyword-friendly parameter (`get_price_on_date(symbol, exchange, date, security_id=None)`, `get_prices(symbol, exchange, from_date, to_date, security_id=None)`, `get_intraday_prices(symbol, exchange, from_datetime, to_datetime, interval="1h", security_id=None)`), matching the call shape the acceptance criteria depict. Make `HistoricalPrice.security_id` / `IntradayHistoricalPrice.security_id` optional (`SecurityId | None = None` in `api_types.py`) so a provider-agnostic call with no security identity can construct prices; keep `PriceSchema`/`IntradayPriceSchema.security_id` required (DB identity is untouched). `src/market/data_router.py` then drops `_NIL_SECURITY_ID` and calls `get_prices` without any security id; legacy callers (`EodhdPriceRepository`, `MarketService`, the CLI commands) keep supplying `security_id=` via a mechanical keyword-only call-site update — behavior and persistence logic unchanged. Rejected alternative: keeping `security_id` first with a `None` default is impossible in Python (a defaulted param cannot precede required ones), and a dual-`@overload` contract would force `*args/**kwargs` dispatch in all ~12 implementations.

**Risks / watch-outs:**
- `ty` union-widening: making the Pydantic field optional makes `PriceSchema.from_historical_price`'s assignment `SecurityId | None -> SecurityId`; the None guard in step 2 is required, not optional polish. Same reasoning applies to any other code that validates a security-id-less price into a DB-bound schema (`repository_eodhd.py:95` uses `PriceSchema.model_validate` on a legacy real-id price, so unchanged) — a security-id-less price must never reach persistence.
- Cache-key drift: `CachedMarketGateway` keys now hash `security_id=None` instead of `UUID(int=0)`; old entries simply miss once and re-fetch — no migration needed, but note it in the PR.
- The nil placeholder is still hardcoded in `tests/market/test_data_router.py` (`_historical_price`, line 111) — update it so the test suite reflects the decoupled contract, not just signatures.
- Do not touch the `market_prices` model (no Alembic migration), `EodhdPriceRepository` merge/persist logic, in line with the Out-of-scope list.
- The price-method param reorder silently binds old positional callers wrong if any are missed; Gate 0 (`ty check`) is the backstop — don't hand-wave it.
